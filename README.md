# Анализ данных ресторана (tips)

Проект по проверке гипотез о факторах, влияющих на размер чаевых.

## Стек
* Python (Pandas, Matplotlib, Seaborn, Plotly)

## Что внутри
* [`Analiz_dannyh_Kvasova-Izotova.pdf`](./Analiz_dannyh_Kvasova-Izotova.pdf) — презентация с результатами и выводами.
* [`Analiz_dannyh_Kvasova-Izotova.ipynb`](./Analiz_dannyh_Kvasova-Izotova.ipynb) — Colab с полным кодом анализа, визуализациями и интерактивными графиками.

## Ключевой результат
Выявлены скрытые закономерности (например, что высокий чек не всегда означает высокий процент чаевых). Сочетание факторов (день недели + время, пол + курение) даёт больше информации, чем изолированный анализ одного признака.
